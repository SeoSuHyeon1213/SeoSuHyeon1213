### 📱AR 서버 모니터링
버넥트(VERNECT)와 함께한 미래내일 일경험 팀 프로젝트로, XR 기반 서버 모니터링 서비스입니다. 버넥트의 XR 개발 툴 Make & View로 제작했고, 글래스모피즘 UI를 적용했습니다. 저는 UI/UX와 소개 영상 편집을 맡았습니다.
- **구성:** 메인화면(서버 위치·요약), 서버 요약(상태·알림), 서버 모니터링(부품별 상태), 실시간 그래프 보기
- **회고:** 노코드 툴의 제약은 별도 서버를 구축하고 그 과정을 GitHub에 문서화해 보완했습니다. "공간감이 부족하다"는 피드백을 받아 반투명 UI로 개선하면서, 피드백을 구체적인 수정 항목으로 바꾸는 법을 배웠습니다.

### 🌳땅따먹기

- **회고:** 입력이 반복되던 문제를 버튼 입력을 상태 변화로 관리해 해결했습니다. 장비를 세트로 묶고 장시간 실행을 점검하면서, 전시에서는 운영 안정성이 중요하다는 점을 배웠습니다.

### 🌠LastNight
바리케이드를 설치하고 아이템을 얻으러 밖으로 나가며 웨이브를 버티는 좀비 TPS입니다.
- **구성:** 웨이브가 쌓일수록 난이도가 오르고, 5웨이브마다 무기 교체, 10웨이브마다 대규모 공격이 있습니다. 특수 좀비(폭발·탱커·딜러·소환형)는 10% 확률로 등장합니다.
- **회고:** 특수 좀비는 상속과 인터페이스로, 총기는 공통 클래스를 상속해 구현하면서 재사용·확장 설계를 익혔습니다. 반복 플레이 테스트로 밸런스를 검증했습니다.
- [GitHub](https://github.com/SeoSuHyeon1213/LastNight)
